# Security policy

## Reporting a vulnerability

Please report security issues privately by email to **vlad@syniavskyi.com**. Do not open a public issue or pull
request for a vulnerability.

Include what you found, how to reproduce it, and the commit or version you tested. You will get an answer as soon as
the maintainer can read the report; please give a reasonable time to fix the problem before disclosing it.

## Scope

This repository is a personal project. It is run by one maintainer and has no bug bounty. Reports about the code in
this repository (authentication, sessions, OAuth/MCP, signup, document handling) are welcome. Never include real
credentials or other people's personal data in a report.
