# Логотипи агентів

`claude.svg`, `claudecode.svg`, `openai.svg`, `codex.svg` скопійовано з пакета
[`@lobehub/icons-static-svg`](https://www.npmjs.com/package/@lobehub/icons-static-svg)
версії 1.101.0 (`icons/<name>.svg`), ліцензія MIT (© LobeHub). Файли не змінено.

Назви й логотипи Claude, Claude Code, ChatGPT/OpenAI і Codex належать їхнім власникам
(Anthropic, OpenAI); тут вони лише позначають агента, якого підключає користувач.

Сторінка підключає їх як маску (`.agent-logo` у `src/ui/theme.css`), без CDN: колір бере з `currentColor`.
