Save your analysis of a job (replaces the previous one). The server validates it, applies the user's hard filters (work mode, seniority, salary, stop words) and returns the flags. gaps: objects with gap and question - one short question (up to 300 characters) for every gap, asking whether the user has experience with it and what exactly (where, for how long); a plain string is still accepted and has no question. The result lists the gaps numbered from 1: show them to the user with their questions. keywords: write one requirement that has several spellings as one item joined with " | " (at most 5 variants, e.g. "Java | Python"). keyword_facts: for each keyword a confirmed fact backs, map it (exactly as written in keywords) to the fact_ids that back it; a fact_id that does not exist is refused.
