Get one step of the job chain add_job → analysis → gaps → reanalysis → cv → cover_letter → apply: its prompt and the step that follows it for this job. name is the step; job_id is required for every step except add_job. Returns name, prompt (do what it says), next (the following step that applies to this job; null after apply) and skip_reason (set: this step does not apply to the job, skip it and go to next). An unknown name is an error that lists the valid names; a job that is not yours or does not exist is not found.
