Funnel of the user's applications by the CV version each was made with. One row per version (document number, save date, keyword coverage) with the number of applications, replies (status replied, interview or offer) and interviews (status interview or offer); rejected and withdrawn applications count only as applications. Applications made without a CV, or before versions were remembered, are grouped under "unknown". Only the latest CV file is kept: a row describes the version the application was sent with, not a file you can open. Use it to see which CV version gets answers.
