Record the user's answer to one gap question of an analysis. gap_number is the gap's number (from 1) in prepare_analysis.previous or save_analysis. has_experience true: pass facts, each one atomic claim (kind and text, max 500 chars, numbers and names as the user said them) in the wording the user approved; call it only after the user says yes and approves the wording of every fact. The facts are saved as confirmed facts of this job (source chat) and close the gap; a text that already exists is linked instead of duplicated, and the analysis becomes stale, so re-run prepare_analysis and save_analysis. has_experience false: send no facts; the no is stored, so never ask again about this gap (prepare_analysis lists gap_answers). A repeated answer to the same gap replaces the previous one.
