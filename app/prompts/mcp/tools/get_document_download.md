Get a single-use link to download a saved CV or cover letter PDF, for attaching it to a form (list_documents pdf_url needs the user's web session, this link needs no session). Pass the document_id from list_documents. Download it right away inside the user's real browser on the form tab: fetch(url) in the extension's JavaScript tool, build a File from the Blob and put it into the form's file input with a DataTransfer. If that fails, download it as a local file with a shell (for example curl -fsS -o <temp dir>/<file_name> <url>) and use the extension's file upload; last resort, open the url in the user's real browser so the PDF lands in the Downloads folder and tell the user which file to attach. The link works once and stops after 10 minutes (expires_at): call this tool again for a new link on every retry.
